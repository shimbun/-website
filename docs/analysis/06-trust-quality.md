## 4. 「COMPASSの考え方」（原稿案）

> 以下は姿勢の骨子案。実際の方針（紹介料の有無等）は【要確認】で、確認後に文言を確定する。

### 4-1. 相談姿勢
- ご家庭の話を最後まで伺い、事実（成績推移・学習状況・お子さまの様子）と、気持ち（不安・焦り・迷い）を分けて整理します。
- 結論を押しつけるのではなく、選択肢とそれぞれのメリット・デメリットを示し、最終的な判断はご家庭で行えるようにします。
- 専門用語はできるだけ使わず、使う場合は意味を説明します。「詳しくないこと」を前提にお話しします。

### 4-2. 中立性
- COMPASSは特定の塾・家庭教師・教材の販売を目的とせず、第三者の立場からご提案します。
- 【要確認】特定の塾・事業者からの紹介料・広告料の受領有無。**受領がない場合のみ**「紹介料等は受け取っていません」と明記。受領がある場合は、その事実と対象を開示する。
- 現在の塾を否定することが目的ではありません。「今の塾で続ける」が最善と考える場合は、そうお伝えします。

### 4-3. ご家庭の方針の尊重
- 受験の目的・志望校・かける時間や費用の考え方は、ご家庭ごとに異なります。COMPASSの価値観で「正解」を決めることはしません。
- 「受験をしない」「志望校を変える」「ペースを落とす」といった選択も、ご家庭の判断として尊重します。
- お子さまの心身の健康を、成績よりも優先して考えます。

### 4-4. 合格保証をしない理由（誠実な説明）
> 「COMPASSは合格を保証しません。」

理由を3点で説明する：
1. **合否は多くの要因で決まるから**：入試当日の問題との相性、体調、倍率など、事前にコントロールできない要素があります。それを「保証」と言い切ることは、誠実ではないと考えます。
2. **学習するのはお子さまご本人だから**：COMPASSが行うのは現状の整理と戦略の提案です。実際の学習は、お子さまと、ご家庭・塾の日々の積み重ねです。
3. **「保証」が判断をゆがめるから**：合格保証を掲げると、お子さまに合った選択より「合格しやすい選択」を優先する動機が生まれます。私たちは、ご家庭にとって納得できる選択を一緒に考えることを大切にしています。

その上で「約束できること」を示す（例：状況を客観的に整理すること／根拠を示して提案すること／分からないことは分からないと伝えること）。

## 5. 支援事例ケーススタディ

### 5-1. フォーマット

```
【事例タイトル】（悩みが伝わる一文。合格校名を見出しにしない）
例：「転塾すべきか迷っていた小5のご家庭が、判断基準を整理して方針を決めるまで」

■ ご家庭のプロフィール（加工済み）
  学年（相談時）／通塾状況（塾名は原則「大手集団塾」等に一般化）／相談時期／利用サービス／相談回数・期間

■ 1. 課題（ご相談時の状況）
  ・保護者の言葉での悩み
  ・客観的な状況（成績・学習時間など、同意の範囲で）

■ 2. 分析（COMPASSが整理したこと）
  ・事実と思い込みの切り分け
  ・原因の仮説と、その根拠

■ 3. 提案（示した選択肢）
  ・選択肢A/B/C と各メリット・デメリット
  ・COMPASSとしての推奨とその理由
  ・ご家庭が選んだ方針

■ 4. 実行（ご家庭が取り組んだこと）
  ・期間／具体的な行動／COMPASSの関わり方（面談頻度など）

■ 5. 結果（事実のみ）
  ・起きた変化（事実）
  ・成績変化を書く場合は【条件】を併記
  ・うまくいかなかった点・残った課題も記載可

■ 担当コンサルタントのコメント
■ 注記：掲載にあたりご本人の同意を得て、個人が特定されないよう一部内容を加工しています。
     成果には個人差があり、同様の結果を保証するものではありません。
```

### 5-2. 記入ガイド

| 項目 | 書くこと | 避けること |
|---|---|---|
| タイトル | 「どんな家庭の・どんな悩みが・どう整理されたか」 | 合格校名、「偏差値○アップ」だけの見出し |
| プロフィール | 一般化した属性 | 塾名・校舎名・地域の細分化・きょうだい構成など特定につながる組合せ |
| 課題 | 保護者が実際に感じていたこと | 不安を煽る脚色 |
| 分析 | COMPASSの思考プロセス（何を見て、何を判断したか） | 「プロの目で見抜いた」等の抽象表現 |
| 提案 | 複数の選択肢と判断根拠 | 唯一の正解を示したかのような書き方、塾批判 |
| 実行 | 主体はご家庭・お子さまであることが分かる書き方 | COMPASSの手柄に見せる書き方 |
| 結果 | 観測できた事実 | 因果の断定（「COMPASSのおかげで合格」） |

### 5-3. 掲載基準（すべて満たすもののみ掲載）

1. **本人同意**：保護者から書面（電子含む）で掲載同意を取得。お子さまが高学年以上の場合は本人の了承も確認することを推奨。同意は撤回可能とし、撤回時は速やかに非公開化。
2. **個人特定不可の加工**：塾名・校舎・学校名・居住地・時期・きょうだい構成等を一般化。**加工は「特定を防ぐため」に限り、成果を良く見せる改変は禁止**。原稿は公開前に保護者へ確認。
3. **結果は事実のみ**：記録（模試成績表・面談記録等）で確認できる事実のみ記載。推測・誇張を書かない。
4. **成績変化は条件を明記**：模試名（一般化可）／比較時点（○年○月→○年○月）／期間／指標（偏差値・順位等）／併行していた取り組み（通塾・家庭教師等）を併記。
5. **合格校の記載**：原則として見出し・強調には使わない。記載する場合も本人同意＋「COMPASSの支援のみによる結果ではない」旨を注記。
6. **うまくいった事例だけに偏らない**：「方針を決めて転塾しなかった」「受験を見送った」など多様な結論の事例を含める。
7. **社内確認**：担当者以外（代表等）が上記基準をチェックし、確認日を記録。

### 5-4. 記入例（1件のみ）

> ### 【サンプル・架空】これは記入方法を示すための架空の例です。実在の事例ではありません。公開しないでください。

**タイトル**：【サンプル・架空】「今の塾を続けるべきか」迷っていた小5のご家庭が、判断の軸を整理して方針を決めるまで

**ご家庭のプロフィール**：【サンプル・架空】小学5年生（相談時）／大手集団塾に通塾／相談時期：5年生の秋／利用：単発の戦略相談＋フォロー面談1回

**1. 課題**：【サンプル・架空】クラスが下がったことをきっかけに、転塾すべきか迷っている。塾の面談では「このまま頑張りましょう」と言われたが、何を頑張ればよいか分からない。家庭学習では宿題が終わらず、親子で言い争いが増えている。

**2. 分析**：【サンプル・架空】直近の模試結果と1週間の学習記録を確認。成績低下は特定の単元の理解不足に集中しており、塾のカリキュラム自体が合っていないとは言い切れないと判断。宿題が終わらない原因は、全問に取り組もうとしていることにあった。

**3. 提案**：【サンプル・架空】A：塾を続け、宿題の取捨選択基準を塾に相談する／B：個別指導を併用する／C：転塾する。それぞれの費用・負担・時期の観点から比較。COMPASSとしてはまずAを試し、次の模試後に再判断することを提案。ご家庭はAを選択。

**4. 実行**：【サンプル・架空】保護者が塾に宿題の優先順位を相談。家庭では取り組む問題に印をつける運用を開始。約2か月後にフォロー面談で状況を確認。

**5. 結果**：【サンプル・架空】宿題を時間内に終えられる日が増え、親子の言い争いが減ったと保護者から報告があった。成績については【条件】○月の模試→○月の模試（同一系統の模試、約2か月、塾は継続）で、算数の該当単元の正答が改善。総合の偏差値は大きな変化なし。転塾は見送り、6年生進級時に再度検討することに。

**担当コメント**：【サンプル・架空】（担当コンサルタントの所感を記入）

**注記**：掲載にあたりご本人の同意を得て、個人が特定されないよう一部内容を加工しています。成果には個人差があり、同様の結果を保証するものではありません。

## 8. 実績数値の表示ポリシー

### 8-1. 基本方針
1. **根拠記録のある数値のみ**掲載する（台帳・予約システム・請求記録等で再現可能なもの）。
2. すべての数値に**「集計期間」「定義」「時点」**を注記する（例：「2025年4月〜2026年3月の相談件数（のべ）。2026年4月1日時点」）。
3. 塾型の「合格者数の大量掲載」はしない（ブランド方針）。
4. 数値が小さい・ない場合は**出さない**。無理に作らない。「開始から間もないため、事例は順次掲載します」等の正直な表現で可。

### 8-2. 掲載可否の判断表

| 数値 | 掲載 | 条件 |
|---|---|---|
| 相談件数（のべ／実家庭数） | 可 | 定義（のべか実数か）・期間・時点を明記 |
| 指導・コンサル経験年数 | 可 | 起算点を定義（例：塾講師としての指導開始年） |
| 満足度（アンケート） | 条件付き可 | 回答数・回答率・設問文・選択肢・期間を併記。n が少ない場合は非掲載 |
| 継続率・リピート率 | 条件付き可 | 算出式を明記 |
| 合格校・合格実績 | 原則非掲載 | 掲載する場合は本人同意・COMPASSの関与範囲の明記・「支援のみによる結果ではない」注記 |
| 偏差値アップ幅 | 原則非掲載（事例内でのみ条件付き） | 5-3の条件を併記。平均値の見出し訴求はしない |
| メディア掲載数 | 可 | 媒体名を一覧で確認可能にする |
| 「No.1」「満足度○%」の比較表現 | 不可 | 第三者調査の根拠がない限り使用しない（景品表示法の優良誤認リスク） |

### 8-3. 運用
- 数値は年1回以上更新し、更新日を表示。
- 根拠資料の保管場所・算出者を社内台帳で管理【要確認】。
