## 0. UX設計の中心原則

| # | 原則 | 具体策 |
|---|------|--------|
| 1 | **今どこにいるか分かる** | パンくず／グロナビのカレント表示／ページ先頭の「ページラベル＋1行要約」／フォームのステップ表示 |
| 2 | **次に何をすればいいか分かる** | 全ページ末尾に「次のステップ」ブロック（相談予約＋関連ページ1〜2件）／スマホ下部固定CTA |
| 3 | **不安を煽らず、安心させる** | 赤・点滅・カウントダウン・「残りわずか」等の緊急演出を使わない。問いかけと共感のトーン |
| 4 | **料金と流れを隠さない** | TOPに料金サマリー、料金ページは税込・所要時間・含まれる内容を明示 |
| 5 | **スマホで片手完結** | 主要操作は親指ゾーン（画面下1/3）に配置、タップ領域は最低 44×44px |
| 6 | **CTAは1種類に統一** | 主CTA文言は全サイトで同一（下記）。副CTAは「料金を見る」「相談の流れを見る」等の情報系のみ |

### CTA文言（推奨）
- **主CTA：「中学受験について相談する」**（無料相談の実施有無が未確定のため「無料」を含めない）
- スマホ下部固定バー等の短縮形：**「相談を予約する」**
- 無料相談の実施が確定した場合のみ、補助テキスト（マイクロコピー）で「初回◯分無料」等を併記（ボタン文言自体は変えない＝統一性優先）
- ボタン下マイクロコピー例：「オンライン対応／所要◯分／しつこい営業はいたしません」（事実確認後に使用）

## 1. デザイン方針（トーン&マナー）

### コンセプト
**「迷ったときに、方角を示す。」— 静かで確かな羅針盤**

中学受験の情報洪水の中で、保護者が落ち着いて「現在地」と「進む方向」を確認できる場所。派手に引っ張るのではなく、**余白・整理・誠実さ**で信頼を得る。

### キーワード
| 軸 | キーワード | デザインへの翻訳 |
|----|-----------|------------------|
| 信頼感 | 誠実・客観・専門 | 深いネイビー基調、整った余白、根拠を示す情報設計 |
| 高級感 | 上質・落ち着き | 真鍮色（ブラス）のアクセントを極少量、明朝体の見出しを限定使用、細い罫線 |
| 清潔感 | 明るい・整頓 | オフホワイト背景、1セクション1メッセージ、要素数を絞る |
| 親しみやすさ | 相談しやすい・やさしい | 角丸（8〜16px）、話し言葉に近い見出し、柔らかい人物写真 |
| 見やすさ | 分かりやすい | 16px以上の本文、1行35〜40字（スマホ）、図解・番号付きステップ |

### やること／やらないこと
| やる | やらない（避ける表現） |
|------|----------------------|
| 問いかけ・共感型の見出し（「〜で迷っていませんか？」） | 「絶対合格」「偏差値◯◯UP保証」等の保証表現 |
| 数字は事実のみ・出典/条件付き | 巨大な合格者数、金バッジ、王冠アイコン、「No.1」 |
| 写真は自然光・実在の人物 | 赤黄の爆発吹き出し、手書き風マーカー多用、極太ゴシックの煽り |
| 装飾は線と余白中心 | 期間限定・残りわずか・カウントダウン |
| 料金を明示 | 長いLP形式の縦長セールスレター、スクロールを延々と続けさせる構成 |
| 色数を絞る（主要3色＋ニュートラル） | グラデーション多用、ネオン、光彩エフェクト |

### モチーフ：COMPASS（羅針盤）の活かし方
- **方位線（細い十字＋円弧）** をセクション背景に薄く（不透明度5〜8%）配置。主張させない。
- **針（ニードル）形状** を「次へ」「現在地」を示すアイコンとして流用（パンくずの区切り、ステップ表示の現在位置マーカー）。
- **「N」の北指針** をロゴ／ファビコン案として検討（ロゴ未確定の場合）。
- セクション見出しの英字ラベルを方位になぞらえる案（例：`01 — WORRIES`、`02 — PERSPECTIVE`）。番号＋英字で「今どの段階か」を示す。
- 利用の流れ（相談→ヒアリング→分析→戦略提案→継続支援）を **「航路」** として1本の線で繋いで図示。

- Ivory/White（ベース）**70%**：Navy（構造・文字）**22%**：Brass（装飾）**5%**：Terracotta（CTAのみ）**3%**

- 赤系エラー色とCTA色が近いため、エラーには必ずアイコン＋テキストを併用（色だけに頼らない）。

## 3. タイポグラフィ

### フォント案
| 用途 | フォント | 理由 |
|------|---------|------|
| 本文・UI | **Noto Sans JP**（400 / 500 / 700） | 可読性・字形の安定性・Google Fonts配信 |
| 見出し（限定使用） | **Shippori Mincho B1**（600） | FVキャッチ・セクション大見出しのみ。上質さと誠実さ。多用すると硬くなるため範囲限定 |
| 英字ラベル・数字 | **Cormorant Garamond**（500）※任意 | セクション番号・英字ラベル（`01 — WORRIES`）に。羅針盤の古典的な品格 |
| 代替（軽量化優先時） | 本文をシステムフォント（`"Hiragino Sans", "Noto Sans JP", sans-serif`）にし、Webフォントは明朝見出しのみサブセット化 | 表示速度（LCP）改善 |

- 読み込みは `font-display: swap`、見出し用明朝は **使用文字のみのサブセット** を推奨（和文フォントは重いため）。
- 合計ウェイトは最大5つまで。

### サイズスケール（スマホ基準／PC）
| トークン | 用途 | スマホ | PC | 行間 | 字間 |
|---------|------|--------|-----|------|------|
| `display` | FVキャッチ（明朝） | 28px | 44px | 1.45 | 0.06em |
| `h1` | 下層ページタイトル | 26px | 36px | 1.45 | 0.05em |
| `h2` | セクション見出し | 22px | 30px | 1.5 | 0.05em |
| `h3` | カード見出し・小見出し | 18px | 21px | 1.55 | 0.04em |
| `h4` | 項目見出し | 17px | 18px | 1.6 | 0.04em |
| `body-l` | リード文 | 17px | 18px | 1.9 | 0.04em |
| `body` | 本文 | **16px** | 16〜17px | **1.85** | 0.04em |
| `small` | 注釈・キャプション | 14px | 14px | 1.7 | 0.03em |
| `label` | 英字ラベル・タグ | 13px（英字のみ） | 13px | 1.4 | 0.12em |
| `button` | ボタン | 16〜17px（700） | 17px | 1.4 | 0.06em |

- **本文は常に16px以上**。和文の注釈も14px未満にしない（特商法・フォーム補足含む）。
- フォーム入力欄は **16px以上**（iOSのズーム防止）。
- 本文1行の最大文字数：スマホ 約21〜24字（画面幅依存）、PC **最大38字前後（max-width 680px目安）**。
- 段落間 1.5em、見出し上マージンは下マージンの約2倍（見出しが次の内容に属することを明確化）。
- 強調は太字（700）のみ。下線・色文字での強調は多用しない（リンクと混同するため）。
- 文字は左揃え（中央揃えは見出しと2行以内の短文のみ）。

## 4. サイトマップ・URL設計

### 方針
- 英語小文字・ハイフン区切り・末尾スラッシュ統一。階層は最大3。

## 5. ナビゲーション

### 5-1. グローバルナビゲーション（PC：1024px以上）
```
+--------------------------------------------------------------------------------+
| [◎ COMPASS 中学受験コンサルタント]   COMPASSとは  サービス▼  料金  事例      |
|                                      コンサルタント  コラム  FAQ   [相談する] |
+--------------------------------------------------------------------------------+
```
- 項目数は **7つ＋CTA** まで：COMPASSとは／サービス／料金／支援事例／コンサルタント／コラム／FAQ ＋［中学受験について相談する］
- 「お客様の声」「ご相談の流れ」はナビに入れず、TOP・サービス・料金ページ内から誘導（ナビ過多を回避）。
- 「サービス」はドロップダウン（6サービスを「悩み」の言葉で表示：例「塾選び・転塾で迷っている」）。クリック/Enterで開閉（ホバーのみに依存しない）。
- スクロール時はヘッダーを縮小（高さ80px→64px）して固定。
- カレントページは **下線（Brass 2px）＋ `aria-current="page"`**。

- 開いたら背面スクロールロック、フォーカスをメニュー内に閉じ込め、Escで閉じる。
- 「閉じる」はテキスト併記。

### 5-3. パンくずリスト
```
TOP  ›  サービス  ›  塾選び・転塾相談
```
- TOP以外の全ページ、ページタイトル直上に表示。区切りは羅針盤の針モチーフ（小さな「›」相当）。
- スマホで長い場合は横スクロールではなく **末尾1階層のみ省略表示**（「… › 塾選び・転塾相談」）。
- 構造化データ（BreadcrumbList）を付与（SEO部と連携）。
- 文字14px／Slate、現在ページはリンクなし＋`aria-current="page"`。

### 5-4. スマホ下部固定CTAバー
```
+----------------------------------------+
| [ 料金を見る ]  [ 相談を予約する  →  ] |  ← 高さ64px＋セーフエリア
+----------------------------------------+
   左：白地・Navy枠（副）  右：Terracotta（主・幅2/3）
```
- **表示条件**：FVの主CTAが画面外に出たら出現（FVとの重複表示を避ける）。
- **非表示条件**：相談予約ページ（フォーム入力中は邪魔になるため）、ソフトキーボード表示中、フッターの最終CTAが見えているとき。
- 料金ページ閲覧中は左ボタンを「相談の流れ」に差し替え（同じ場所にいる導線を出さない）。
- `env(safe-area-inset-bottom)` を考慮。本文最下部に同じ高さの余白を確保し、コンテンツを隠さない。
- 半透明ぼかし背景は不可（コントラスト不安定）。白背景＋上部に1px罫線＋薄い影。
- LINE相談を実施する場合は右ボタンを分割せず、左を「LINEで相談」に置換する案を検討（→11章）。

### 5-5. 「現在地」と「次の一歩」を示すUIの共通ルール
| 要素 | 内容 |
|------|------|
| ページヘッダー | パンくず → 英字ラベル → H1 → 1行要約（「このページでは◯◯が分かります」） |
| 長いページの目次 | 料金・サービス詳細・コラム・FAQでは冒頭に目次（ページ内リンク）。スマホは折りたたみ式 |

## 7. 主要コンポーネント設計

### 7-1. ファーストビュー
| 項目 | 仕様 |
|------|------|
| 構成（スマホ） | 写真（上）→ ラベル → キャッチ → リード → 主CTA → マイクロコピー → 信頼チップ |
| 構成（PC） | 左：テキスト＋CTA（5/12カラム）／右：写真（7/12）。写真に文字を重ねない |
| 高さ | スマホで **主CTAが初期表示内（ファーストビュー内）に収まる** こと（375×667で確認） |
| キャッチ | 「中学受験、誰に相談していますか？」（brief指定） |
| 信頼チップ | 事実のみ（例：特定の塾に属さない中立の立場／料金を明示）。数値実績は根拠がある場合のみ |
| 禁止 | 自動再生スライダー、動画背景、パララックス、ポップアップ |

### 7-2. CTAボタン
| 種類 | 見た目 | 用途 |

| Primary | Terracotta `#A8431F` 背景・白文字700・角丸12px・高さ56px（スマホ全幅／PC 最小幅320px）・右に針型矢印 | 相談予約のみ |

### 7-8. 相談予約フォーム
**方針：入力項目を最小化し、3ステップで「あとどれくらいか」を常に示す。**

ステップ表示：
```
  ● 入力 ───── ○ 確認 ───── ○ 完了
  STEP 1 / 3　（約2分）
```

**必須項目（最小構成：5項目）**
| # | 項目 | 形式 | 補足 |
|---|------|------|------|
| 1 | 保護者のお名前 | text（1欄） | 姓名分割しない。ふりがなは任意または削除 |
| 2 | メールアドレス | email | `autocomplete="email"`、`inputmode="email"` |
| 3 | お子さまの学年 | ボタン選択（年長〜小6／その他） | プルダウンよりタップしやすいセグメント型 |
| 4 | ご相談したいこと | チェックボックス（複数可・6カテゴリ＋その他） | サービスと同じ分類 |
| 5 | 希望日時 | 予約カレンダー連携 or 第1〜第2希望（日付＋時間帯） | 予約システム有無で分岐（→11章） |

**任意項目**
- 電話番号（連絡手段として電話希望の場合のみ表示＝条件分岐）
- 現在の状況・ご相談内容の詳細（テキストエリア、「分かる範囲で・空欄でも大丈夫です」と明記）
- 通塾状況（通塾中／検討中／なし）
- COMPASSを知ったきっかけ（マーケティング計測用。任意・最後尾）

**UI仕様**
- 1カラム、ラベルは入力欄の上（プレースホルダーをラベル代わりにしない）。
- 必須は「必須」テキストバッジ（色だけ・＊だけにしない）。任意側に「任意」を付ける方式でも可（必須が多数派の場合）。
- エラーは **フィールド直下にアイコン＋具体的な文言**（「メールアドレスの形式をご確認ください（例：name@example.com）」）＋送信時にページ上部にエラー要約とリンク。
- 入力中の内容は確認画面から戻っても保持。セッション内一時保存。
- 送信ボタン直上に「プライバシーポリシーに同意のうえ送信」＋リンク（チェックボックスは法務判断で要否決定）。
- 送信ボタン文言：「確認画面へ進む」→ 確認画面「この内容で予約を申し込む」。
- フォーム周辺に不安解消情報：「送信後、◯営業日以内にメールでご連絡します」「無理な勧誘はいたしません」（事実確認後）。
- フォームページでは下部固定CTA・ヘッダーのCTAを非表示、グロナビは簡略化（離脱防止しつつ戻れる導線は残す）。

## 9. 写真・イラスト方針

### 全体方針
- **写真主体、イラストは最小限**。イラストはアイコン（線画）と図解、404の羅針盤のみ。
- トーン：自然光、やや暖かい色温度、彩度控えめ（-10〜-15%程度）、ハイライトを飛ばさない。全写真で同一のカラーグレーディング。
- **フリー素材の「いかにも」な人物写真（ガッツポーズの子ども、ハチマキ、合格発表の歓喜、指差しで笑うスーツ）を使わない**。
- 素材サイトを使う場合も、人物より「手元・ノート・机・窓辺・本棚」など **抽象度の高い静物** を優先。
- 合格発表・偏差値表・大量の参考書の山など受験の緊張を煽るビジュアルは使わない。

### 人物写真の撮影指針（コンサルタント・面談イメージ）
| 項目 | 指針 |
|------|------|
| 被写体 | 実在のコンサルタント本人（必須）。保護者役はモデル起用 or 後ろ姿・手元で表現 |
| 表情 | 口角を上げた穏やかな表情。満面の笑み・腕組み・威圧的ポーズは避ける |
| 服装 | ネイビー／白／ベージュ系の清潔なジャケットスタイル（ブランドカラーと調和）。ノーネクタイ可 |
| 構図 | ①プロフィール用：胸上・正面〜やや斜め・背景ぼかし（4:5）②面談風景：机を挟まず斜め横に座る「一緒に考える」構図 ③手元：資料を指し示す・メモを取る |
| 背景 | 明るい書斎・ライブラリー風、観葉植物少量。塾の教室・ホワイトボード前は避ける（塾っぽさ回避） |
| 光 | 窓光中心、ストロボは補助。影を柔らかく |
| オンライン相談 | PC画面越しに話す自然なカット（画面内は架空の内容、個人情報を映さない） |
| 子ども | 原則、顔の分かる写真は使わない（後ろ姿・手元）。使う場合は保護者の書面同意とモデル契約 |
| 必要カット数目安 | FV用（横長・縦長トリミング両対応）1、プロフィール 各2、面談風景 3〜5、手元・静物 5〜8、OGP用 1 |

### 画像の技術的扱い（実装部への申し送り）
- WebP/AVIF＋フォールバック、`srcset`でスマホ用を配信、`width/height`指定でCLS防止、FV以外は遅延読み込み。
- 代替テキスト：情報を持つ写真は内容を簡潔に記述、装飾画像は `alt=""`。
- お客様の声・事例に写真を付けない（捏造と誤解されるリスク回避）。

### アイコン・図解
- 線画・線幅1.5px・角丸端・Navy or Brass の2色まで。絵文字は使わない。
- 図解（第三者の立場、流れ、事例ステップ）は文字情報を画像内に閉じ込めず、HTMLテキストで実装（アクセシビリティ・SEO）。
