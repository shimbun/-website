### 1-B 特定継続的役務提供（家庭教師等・学習塾）該当性の検討　★要

**制度概要（一般的理解）**

| 項目 | 家庭教師等 | 学習塾 |
|---|---|---|
| 役務の内容 | 学校（幼稚園・小学校を除く）の入学試験に備えるため、または学校教育（大学・幼稚園を除く）の補習のための**学力の教授** | 同左 |
| 提供場所 | 事業者が用意する場所**以外**（自宅訪問、電話・オンライン等を含むとされる） | 事業者が用意する場所（教室等） |
| 期間要件 | **2か月を超える** | **2か月を超える** |
| 金額要件 | **5万円を超える**（入会金・教材等の関連費用を含む総額で判断されるとされる。算定範囲は★要） | 同左 |
| 主な義務・効果 | 概要書面・契約書面の交付（相手方承諾があれば電磁的方法も可）、クーリング・オフ8日、中途解約権、誇大広告等の禁止、不実告知等の禁止、前受金保全関連の書類備置 | 同左 |
| 中途解約時の損害賠償等の上限 | 提供開始前：2万円／開始後：提供済み役務の対価＋「5万円または1か月分の対価のいずれか低い額」 | 提供開始前：1万1千円／開始後：提供済み役務の対価＋「2万円または1か月分の対価のいずれか低い額」 |

**中学入試は「幼稚園・小学校を除く学校の入学試験」に該当する**ため、中学受験対策は対象領域に入り得ます。論点は「保護者へのコンサルティングが『学力の教授』に当たるか」です。

**判定フロー（設計案。最終判断は★要）**

```
Q1. 契約期間は2か月を超えるか？（自動更新・実質一体の複数契約は合算して考える前提で）
   └ No → 特定継続的役務提供には原則該当しない（通信販売等の規律は残る）
   └ Yes → Q2
Q2. 支払総額（入会金・教材・関連商品等を含む、税込）は5万円を超えるか？
   └ No → 原則該当しない
   └ Yes → Q3
Q3. 役務に「子ども本人への学力の教授」が含まれるか？
     例：子どもへの教科指導、問題の解説、答案添削、子ども本人への学習コーチング・勉強法指導
   └ Yes → 該当可能性が高い（家庭教師等 or 学習塾）→ 特商法対応一式が必要
   └ No（保護者のみを相手に、塾選び・志望校選び・学習計画の方針等を助言） → Q4
Q4. 保護者向けでも実質的に学力向上のための学習指導（詳細な学習計画作成と進捗管理、
     過去問の取組み方の個別指導等）を主内容とし、「成績向上」を訴求しているか？
   └ Yes → グレー。安全側として該当前提の対応を検討
   └ No → 該当しない可能性が高い（ただし広告表現で「学力の教授」と受け取られない設計が必要）
```

**推奨方針**

1. 継続コンサルの**サービス内容を明文化**（相手方＝保護者、内容＝情報整理・方針提案、子ども本人への教科指導は行わない等）し、弁護士に該当性の見解を得る。
2. 見解が得られるまでは**安全側設計**：2か月超かつ5万円超の継続プランには、概要書面・契約書面、8日間のクーリング・オフ、中途解約規定（上記上限以内）を用意できる体制を前提とする。
3. 代替案：継続プランを「月単位・前払いは1か月分のみ・いつでも解約可」とする設計は消費者リスクを下げるが、**自動更新や実質一体契約は期間合算と判断され得る**ため、回避策としての有効性は★要。
4. 広告表現で「指導」「授業」「成績を上げる」を多用すると学力の教授と受け取られやすい。「相談」「整理」「提案」「伴走」を基本語彙とする（2章）。

### 1-C 電気通信事業法 外部送信規律の適用可能性（2023年6月16日施行）

- 規律対象は「電気通信事業者」及び「第三号事業を営む者」（検索サービス、SNS、各種情報のオンライン提供等を行う者）で、利用者の端末から外部へ情報を送信させるタグ等を設置する場合に、通知・公表等が求められる。
- 総務省の解説では、**自社の商品・サービスの紹介・販売を目的とするWebサイト**は、一般に「他人の需要に応ずる」電気通信役務ではなく、規律の対象外とされている。本サイトは自社サービスの紹介・相談受付が主目的のため、**対象外である可能性が高い**。
- ただし次の場合は再検討：コラムを独立したメディアとして運営し広告収入を得る／会員登録制の情報提供・コミュニティ機能を設ける／保護者同士の掲示板やチャット機能を設ける。
- **推奨**：法的義務の有無にかかわらず、プライバシーポリシー内または別ページで「Cookie・外部送信について」（送信先事業者名、送信される情報、利用目的、オプトアウト方法）を公表する。Cookie同意バナーは日本法上一般には必須ではないが、広告タグ導入時は導入を検討。
- 専門家確認：☆推奨（機能追加時は★要）

## 2. 表現ガイドライン（NG → OK 対照表）

**基本原則**
1. 事実のみ、根拠資料を保管できるもののみ表示する（不実証広告規制）。
2. 将来の不確実な結果（合格・成績向上）を断定しない（景表法・消費者契約法4条1項2号「断定的判断の提供」）。
3. 条件・例外は強調表示の近く・同じ視認性で示す（打消し表示は小さく離れた注記では不十分とされる）。
4. 不安を煽らない（ブリーフ絶対ルール4）。

### 2-1 合格実績

| NG表現 | 問題点 | OK表現（例） |
|---|---|---|
| 「合格保証」「絶対合格」「必ず合格できる」 | 断定的判断の提供、優良誤認 | 「合格に向けた戦略を、ご家庭と一緒に考えます」 |
| 「合格率98%」（母数・定義不明） | 優良誤認。母数の恣意的選択 | 原則掲載しない。掲載する場合：「20XX年度 継続コンサル（3か月以上）ご利用〇名のうち、第一志望校合格〇名（ご家庭からのご報告ベース）」と定義・期間・母数・集計方法を併記 |
| 「〇〇中 合格者多数」 | 「多数」の根拠不明、単発相談者を含めた水増し | 「支援事例」で個別の経緯を紹介（数を誇らない）。数を出す場合は定義を明記 |

## 3. お客様の声・支援事例の掲載ルールと同意書項目案

### 3-1 掲載ルール

1. **実在性**：実際にサービスを利用した保護者本人の声のみ。原文（アンケート・メール等）と同意書を保管（最低：掲載期間＋〇年【要確認】）。
2. **同意**：書面または電磁的方法で個別同意。子どもに関する記述は保護者の同意に加え、子どもの年齢に応じて本人の意向にも配慮。
3. **匿名化**：原則「地域（都道府県または首都圏等）＋学年＋保護者」。学校名・塾名は、本人同意があり、かつ特定リスクが低い場合のみ。合格校名＋学年＋地域＋年度の組合せで個人が特定されないか確認。
4. **編集範囲**：誤字脱字修正、長文の要約、個人特定情報の削除のみ。趣旨・評価の程度を変えない。編集後原稿を本人に確認。
5. **謝礼**：謝礼（割引・ギフト等）を提供した場合はその旨を把握・記録し、自社サイト内の掲載でも「掲載にご協力いただいた方に〇〇を進呈しています」等の開示を検討。外部媒体での投稿依頼は広告表示必須。
6. **選別**：否定的な声を削除すること自体は直ちに違法ではないが、「利用者全員が満足」と誤認させる表示はしない。
7. **撤回**：掲載後も撤回可能。撤回申出から〇営業日以内【要確認】に削除（SNS・印刷物等の既配布分は対応範囲を同意書で明示）。
8. **根拠保管**：成績・合否を記載する場合は、本人申告内容の記録を保管。
9. **支援事例**：守秘義務との関係で、同意がない事例は掲載しない。モデルケースは明示。
10. **定期見直し**：年1回、掲載中の声・事例の同意有効性と表示の適正を点検。

## 8. 免責事項の文案方針

**方針**
1. **全部免責・一律免責は書かない**。消費者契約法8条により、事業者の損害賠償責任の全部免除、故意・重過失による責任の一部免除は無効。2023年6月施行改正により、軽過失の場合に限る一部免除である旨を明らかにしない条項（「法令に反しない限り」だけの記載等）も無効とされる。
2. **サービスの性質を正確に説明する**ことで期待値を調整する（「合否・成績は保証しない」は、事実として保証していないことの説明として記載可）。
3. **情報提供（コラム・FAQ）と個別相談を分けて書く**。
4. 読みやすく、「突き放した」印象を与えないトーン（ブランド：誠実・親身）。

**文案の方向性（例示。最終文面は★要）**

- サービスの性質：「COMPASSのコンサルティングは、中学受験に関する情報の整理と方針のご提案を行うものです。志望校への合格や成績の向上をお約束するものではありません。最終的なご判断は、ご家庭でお願いいたします。」
- 責任の制限：「当方の責めに帰すべき事由によりご利用者さまに損害が生じた場合、当方は、当方に故意または重大な過失がある場合を除き、当該サービスについてご利用者さまから受領した料金の額を上限として賠償責任を負います。」
- コラム・サイト情報：「当サイトの情報は掲載時点のものです。入試制度・日程・募集要項等は変更されることがあるため、必ず各学校・公式情報をご確認ください。」
- 外部リンク：「リンク先サイトの内容について当方は管理しておらず、その内容を保証するものではありません。」
- 医療・心理領域：「お子さまの心身の健康や発達に関するご心配については、医療機関等の専門機関へのご相談をおすすめします。」
- 掲載場所：利用規約（責任制限の本体）、サイト共通フッター「免責事項」ページまたはサイトポリシー（情報提供に関する免責）、料金・サービスページ（保証しない旨を短く）。
