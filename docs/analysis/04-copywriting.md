## 0. コピーの基本姿勢（全ページ共通の原則）

| 原則 | 内容 |
|---|---|
| 売るより「整理する」 | 「合格させます」ではなく「今の状況を一緒に整理します」。主語は保護者とお子さま、COMPASSは伴走者 |
| 不安を煽らない | 「このままでは手遅れ」型の恐怖訴求は使わない。不安は「よくあること」として受け止め、次の一歩を示す |
| 第三者性 | 特定の塾・教材・学校を売らない立場であることを、根拠とともに繰り返し伝える（【要確認：塾・教材等からの紹介料や提携の有無】） |
| 合格保証をしない | 合否は結果として語らない。「判断材料」「選択肢」「納得感」を価値として語る |

| 数字と実績は事実のみ | 相談件数・合格実績・満足度などは確認済みのもの以外記載しない |
| 料金を隠さない | 料金は明示。「詳しくはお問い合わせ」で終わらせない |
| スマホで読める長さ | 1文40〜60字目安、1段落3文以内。見出しは20字前後まで |

## 1. トーン&ボイスガイド

### 1-1. ボイス（人格）
「落ち着いた、話を最後まで聞いてくれる、受験に詳しい相談相手」。
先生口調・営業口調ではなく、**丁寧語（です・ます）でやわらかく、断定しすぎない**。

| 軸 | こうする | こうしない |
|---|---|---|
| 専門性 | 根拠や考え方を短く添える | 専門用語・業界用語を並べる |
| 親身さ | 「〜と感じていらっしゃる方も多いです」と受け止める | 「〜ではありませんか？」と責める・詰める |
| 客観性 | 「選択肢」「判断材料」「整理」 | 「正解はこれ」「これしかない」 |
| 誠実さ | できないこと・向かないケースも書く | 何でもできると言う |
| 分かりやすさ | 一文一義、結論から | 長い前置き、抽象語の連続 |

### 1-2. 使う言葉（推奨語彙）
整理する／一緒に考える／判断材料／選択肢／客観的に／第三者の立場から／お子さまに合った／ご家庭の方針／納得して選ぶ／状況を見える化する／次の一歩／伴走／相談しやすい／お気軽に（多用しない）／〜という考え方もあります

| 偏差値○アップ保証／成績が必ず上がる | 効果保証 | 「成績の伸び悩みの原因を一緒に探ります」 |

### 1-4. 表記ルール
- 「お子さま」で統一（子ども／お子様は不使用）。「保護者さま」ではなく「保護者の方」。
- 数字は半角算用数字。金額は「○○円（税込）」【要確認：税込表示】。
- 「中学受験」で統一（「中受」は不使用）。
- 感嘆符「！」は原則不使用。CTAにも付けない。
- 学年は「小学4年生」→ 見出し等の短縮時のみ「小4」。

| E | 中学受験にも、セカンドオピニオンを。 | コンセプトを最短で伝える。一方「セカンドオピニオン」が保護者に伝わるかは要検証 |

### 推奨：B（A＋第三者の補足）
```
中学受験、誰に相談していますか？
塾でも家族でもない、第三者という選択肢。
```
**理由**
1. 指示書の軸コピーをそのまま主見出しに残し、問いかけの強さを保てる。
2. 2行目で「何のサービスか（第三者の相談先）」が3秒で分かる。問いかけのみ（A）だとサービス内容が伝わりにくい。
3. 「セカンドオピニオン」という言葉（E）はFV下のサブコピーで説明付きで使う方が、初見の保護者に誤解が少ない。
4. 煽り・保証・最上級表現を一切含まず、ブランド要件（誠実・客観的・相談しやすい）に合致。
5. スマホで2行に収まる（各行20字以内）。

※ SEO上のh1は「中学受験の相談・セカンドオピニオン｜COMPASS 中学受験コンサルタント」など検索語を含める案を Agent（SEO担当）と調整。

## 5. 「COMPASSとは」ページ 原稿骨子

1. **ページ見出し**：中学受験に、セカンドオピニオンという考え方を。
2. **導入（共感）**：中学受験の情報はたくさんあるのに、「わが家の場合はどうすればいいのか」を相談できる場所は意外と少ない。塾には塾の、家族には家族の立場がある。
3. **セカンドオピニオンとは**：
   - 医療で、主治医とは別の医師に意見を聞くこと。主治医を否定するためではなく、納得して治療を選ぶため。
   - 中学受験でも同じように、今の塾・学習方法を続けるかどうかを含めて、別の視点から確認できる。
4. **COMPASSの立場（中立性）**：
   - 特定の塾・学校・教材を勧めることで利益を得る仕組みがない【要確認：提携・紹介料・アフィリエイト等の有無】。
   - 今の塾をやめさせることが目的ではない。「今の塾を続ける」が最善という結論もありうる。
5. **COMPASSがすること／しないこと**（誠実さの可視化）

   | すること | しないこと |
   |---|---|
   | 状況・資料（成績・模試・学習記録）の整理 | 合格の保証 |
   | 課題の優先順位づけ | 特定の塾や教材の押し売り【要確認】 |
   | ご家庭に合う選択肢の提示 | 塾や先生の批判 |
   | 継続的な伴走（希望者のみ） | 授業・指導そのもの【要確認：指導サービスの有無】 |

6. **名前の由来**：COMPASS＝方角を示す道具。ゴール（志望校）を決めるのはご家庭、COMPASSは進む方向を確かめる道具でありたい。【要確認：名称の由来の公式な説明】
7. **大切にしている姿勢**（TOP§6と共通の3〜5点）
8. **代表メッセージ**【要確認：代表者名・写真・原稿】
9. **CTA**：中学受験について相談する

## 6. サービス6種 説明文

各サービス共通の構成：キャッチ／こんな方に／相談できること／得られるもの／料金【要確認】／CTA
※「得られるもの」は成果保証にならないよう「整理された状態」「判断材料」として書く。

### 6-1. 中学受験 戦略相談
- **キャッチ**：受験するかどうか、から一緒に考えます。
- **こんな方に**：受験するか迷っている／何から始めればいいか分からない／受験全体の見通しを持ちたい／保護者自身が中学受験に詳しくない
- **相談できること**：受験する・しないの判断材料／開始時期と塾通いのタイミング／学年ごとの全体スケジュール／ご家庭の負担（時間・費用）の見通し
- **得られるもの**：ご家庭の方針に沿った受験全体の見取り図と、今やるべきことの優先順位

### 6-2. 成績・学習相談
- **キャッチ**：成績が伸びない理由を、一緒に探ります。
- **こんな方に**：成績が伸び悩んでいる／模試の結果をどう読めばいいか分からない／勉強時間の割に結果が出ない／勉強方法が合っているか不安
- **相談できること**：模試結果・成績推移の読み解き／科目ごとの課題の整理／勉強方法・学習計画の見直し／過去問の取り組み方
- **得られるもの**：課題の原因と優先順位の整理、お子さまに合った学習の進め方の提案

### 6-3. 志望校・併願校相談
- **キャッチ**：偏差値だけでなく、お子さまに合う学校を。
- **こんな方に**：志望校の選び方が分からない／志望校を変更するか迷っている／併願の組み方に不安がある
- **相談できること**：学校選びの軸づくり（校風・通学・教育方針など）／志望校の見直し／併願校の組み合わせと受験日程の考え方
- **得られるもの**：ご家庭が納得できる志望校・併願校の候補と、その選び方の理由

### 6-4. 塾選び・転塾相談
- **キャッチ**：塾を変えるべきか、続けるべきか。どちらの結論もありえます。
- **こんな方に**：初めての塾選びで迷っている／今の塾が合っているか不安／転塾を考えている／家庭教師や個別指導の併用を検討している
- **相談できること**：塾ごとの特徴の比較の視点／今の塾での課題の整理／転塾のメリット・注意点とタイミング／家庭教師・個別指導の併用の考え方
- **得られるもの**：特定の塾に偏らない比較の視点と、ご家庭が選ぶための判断材料【要確認：特定塾との提携がないこと】

### 6-5. 家庭学習相談
- **キャッチ**：家での勉強、どこまで親が関わればいい？
- **こんな方に**：家庭学習の見方が分からない／親子関係がぎくしゃくしている／宿題が回らない／スケジュール管理に困っている
- **相談できること**：家庭学習の時間の使い方／宿題・復習の優先順位／保護者の関わり方／声かけや親子のコミュニケーション
- **得られるもの**：無理なく続けられる家庭学習の形と、保護者の役割の整理

### 6-6. 継続コンサルティング
- **キャッチ**：受験が終わるまで、定期的に一緒に見直します。
- **こんな方に**：単発ではなく継続して相談したい／模試のたびに方針を確認したい／直前期まで伴走してほしい
- **相談できること**：上記5領域すべて／定期面談での進捗確認と計画の見直し【要確認：面談頻度・期間・連絡手段（チャット等）】
- **得られるもの**：状況の変化に合わせて、その都度方針を調整できる相談相手
- **注記**：継続契約を強くお勧めすることはありません。単発のご相談だけでも大丈夫です【要確認】。
