### 1-2. チャネル別補足

- **検索は「悩み語」と「相談語」の2層で設計**
  - 悩み語（情報収集）：「塾 合わない サイン」「志望校 決め方 5年生」「過去問 いつから」→ コラム
  - 相談語（顕在）：「中学受験 相談」「中学受験 セカンドオピニオン」「転塾 相談 どこ」→ サービス詳細 / LP
- **「セカンドオピニオン」という言葉の認知度は保護者間で高くない可能性**。検索キーワードとしては「第三者」「塾以外に相談」「客観的な意見」も併用する。
- **SNS は煽りの多い環境**のため、COMPASS のトーン（冷静・誠実・整理する）自体が差別化要素になる。

## 2. カスタマージャーニー

| フェーズ | 保護者の状態・行動 | 主な疑問・感情 | 主な接点 | サイト/施策で提供するもの | 次へ進めるKPI（仮） |
|---|---|---|---|---|---|
| **認知** | 受験検討・通塾開始・成績停滞などをきっかけに情報収集を始める | 「周りはどうしているのだろう」「このままで大丈夫？」 | 検索・Instagram・X・紹介・YouTube | 悩みに寄り添うコラム、SNS 投稿。「塾以外にも相談先がある」という選択肢の提示 | 記事閲覧、SNS フォロー/保存 |
| **興味** | 「第三者に相談する」という発想を知る | 「セカンドオピニオンって何をしてくれるの？」「塾と何が違う？」 | TOP・COMPASSとは・SNS プロフィール | 「第三者だからできること」、相談できることの一覧、塾との役割の違い（批判ではなく補完） | TOP→サービス遷移率、LINE 登録 |
| **比較検討** | 家庭教師・個別指導・他の相談サービス・塾の面談と比べる | 「料金はいくら？」「誰が相談に乗るの？」「うちの悩みも対象？」 | サービス詳細・料金・コンサルタント・支援事例 | 料金を明示、コンサルタントの経歴（事実のみ）、支援事例（課題→分析→提案→実行→結果） | 料金ページ閲覧、事例閲覧 |
| **不安解消** | 相談直前の心理的ハードル | 「勧誘されない？」「こんな初歩的なことを聞いていい？」「塾に知られない？」「オンラインで大丈夫？」 | FAQ・利用の流れ・お客様の声 | FAQ（勧誘・守秘・準備物・キャンセル）、流れの図解、相談前に準備するもの | FAQ閲覧→予約フォーム遷移 |
| **相談予約** | フォーム入力 | 「入力が面倒」「何を書けばいい？」 | 相談予約ページ・LINE | 入力項目最小化、日程選択、相談内容は選択式＋任意自由記述、完了後の案内 | フォーム到達率・完了率 |
| **相談実施** | 初回相談 | 「整理できた」「次に何をすべきか分かった」 | オンライン/対面相談 | 相談後のサマリー提供（運用確認要）、継続プラン案内（押し売りしない） | 相談実施率（予約→実施） |
| **継続** | 継続コンサル・スポット再相談・紹介 | 「節目ごとに相談したい」「友人にも勧めたい」 | 継続コンサル・LINE・メール | 学年・時期ごとの再相談案内、紹介の仕組み、お客様の声の収集（許諾前提） | 継続率、再相談率、紹介数 |

**ジャーナー全体の設計原則**
1. 「今すぐ相談」と「まずは情報を得たい」の2つの出口を常に用意する（相談予約／LINE）。
2. 比較検討フェーズで離脱させないため、**料金・相談者・流れの3点を2クリック以内**で確認できるようにする。
3. 不安解消フェーズは FAQ だけに頼らず、予約フォーム直前にも「よくある不安」3点を再掲する。

## 3. サイト内ユーザー導線

### 3-1. パターン1：TOP 起点（指名検索・紹介・SNSプロフィール経由）

```
TOP（FV「中学受験、誰に相談していますか？」＋CTA）
 ├─ お悩み一覧 ──→ 該当サービス詳細（6種） ──→ 料金 ──→ 相談予約
 ├─ 第三者だからできること / COMPASSとは ──→ コンサルタント ──→ 相談予約
 ├─ 支援事例 ──→ 事例詳細 ──→ 関連サービス ──→ 相談予約
 ├─ 料金（TOP内サマリー）──→ 料金ページ ──→ 相談予約
 └─ FAQ（TOP内抜粋）──→ FAQ ページ ──→ 相談予約 / LINE
```
- 想定ユーザー：紹介・指名検索が中心で温度感が高い。**FV 直下にもCTA**、かつ「料金」「コンサルタント」へ早く到達できるアンカーを設置。
- 迷った人向けに「どのサービスを選べばいいか分からない方へ → まずは戦略相談」の受け皿を明記。

### 3-2. パターン2：SNS 起点（Instagram/TikTok/X/SNS広告）

```
SNS投稿 / 広告
 → プロフィールリンク or 広告
   → SNS用LP（共感→第三者の価値→相談できること→料金→流れ→FAQ→CTA）
      ├─ 主：相談予約
      └─ 副：LINE 友だち追加 → 定期配信 → 相談予約（数日〜数か月後）
```
- 想定ユーザー：温度感低〜中。スマホで短時間閲覧。**LP 内で完結**させ、サイト回遊に依存しない。
- Instagram のプロフィールリンクは「リンク集ツール」ではなく **自社 LP へ直接** 遷移（計測と信頼感のため）。
- 投稿テーマと LP 冒頭の悩みを一致させる（メッセージマッチ）。

### 3-3. パターン3：検索記事起点（自然検索でコラムへ着地）

```
検索「5年生 転塾 時期」
 → コラム記事（結論→解説→家庭で確認すること）
   ├─ 記事中：関連記事（同カテゴリ）
   ├─ 記事中盤：控えめなテキストCTA「状況を整理したい方へ：塾選び・転塾相談」
   ├─ 記事末：サービス誘導ボックス（該当サービス名・できること・料金目安・CTA）
   └─ LINE 登録ボックス（「今すぐではない方へ」）
 → サービス詳細（塾選び・転塾相談）→ 料金 / FAQ → 相談予約
```
- 記事は **1記事1悩み**、記事カテゴリ＝サービスカテゴリ（6種）と対応づけ、記事→サービスの内部リンクを機械的に設置できる構造にする。
- 記事内で相談を押し売りしない。**記事単体で役立つこと**を優先し、信頼の結果として相談に進んでもらう。

## 5. CTA 設計

### 5-1. 文言案の比較

| 文言案 | 長所 | 短所 | 評価 |
|---|---|---|---|
| 中学受験について相談する | 何ができるか明確。誠実。無料/有料に依存しない | やや長い。行動の軽さが弱い | ◎（主CTA） |
| まずは相談してみる | 心理的ハードルが低い | 「何の相談か」が文脈依存。単独だと曖昧 | ○（補助） |
| 相談を予約する | 行動が具体的 | 硬い印象、温度感の低い人には重い | ○（予約ページ直前） |
| 相談内容と料金を見る | 比較検討層に効く、押し売り感ゼロ | CVに直結しない | ○（中間CTA） |
| 無料相談はこちら | CVR は上がりやすい | **無料相談が実施されていない場合は使用不可** | パターンBでのみ使用 |
| 今すぐ申し込む / 限定◯名 | 即効性 | 煽り・情報商材感。ブランドに反する | ×（使用しない） |

### 5-2. パターンA：無料相談を実施しない場合（**確定まで既定**）

| 用途 | 文言 | 補足マイクロコピー（ボタン下・近傍） |
|---|---|---|
| 主CTA（FV・最終CTA・固定CTA） | **中学受験について相談する** | 「オンライン対応／初回の流れと料金はこちら」※実施内容に合わせて要確認 |
| 中間CTA（セクション間） | 相談内容と料金を見る | ― |
| 記事末CTA | 〇〇について相談する（例：塾選び・転塾について相談する） | 該当サービス名を差し込み |
| 予約フォーム送信 | 相談を予約する（内容を送信） | 「送信後、◯営業日以内にご連絡します」※日数は要確認 |
| LINE CTA | LINEで相談の流れを受け取る ／ LINEで最新情報を受け取る | 「売り込みの連絡はしません」※運用方針確認後に記載 |

- 料金を CTA 付近に**併記**し、「クリックしたら有料と知った」という不信を防ぐ（ブリーフ：料金を隠さない）。

### 5-3. パターンB：無料相談を実施する場合（**実施確認後にのみ切替**）

| 用途 | 文言 | 補足マイクロコピー |
|---|---|---|
| 主CTA | **無料で相談してみる**（または「無料相談を予約する」） | 「◯分・オンライン」「無理な勧誘はありません」※内容確認後 |
| 中間CTA | 無料相談でできることを見る | ― |
| 記事末CTA | 〇〇について無料で相談する | ― |
| LINE CTA | LINEで無料相談を予約する | LINE 経由予約を実施する場合 |

- 無料相談の**範囲・時間・回数・有料プランとの違い**を明記すること（景品表示法・誤認防止）。
- 「無料」を強調しすぎると「無料の後に勧誘される」不安を生むため、「勧誘しない方針」の明記とセットで使う。

### 5-4. 推奨

- **主CTA は「中学受験について相談する」で全ページ統一**（パターンA）。無料相談が確定した場合のみ主CTAを「無料で相談してみる」へ切替。
- 文言は CMS/設定値で一括変更できる構造にしておく（実装側への要望）。
- 色・形状は主CTA 1種に統一。LINE ボタンは LINE ブランドカラーを使いつつ、主CTAより視覚的優先度を1段下げる。

### 5-5. 配置ルール

| # | ルール |
|---|---|
| 1 | FV 内に主CTA を必ず1つ（スクロールなしで見える位置） |
| 2 | TOP は「お悩み」後／「選ばれる理由」後／「料金」後／「FAQ」後／最終CTA に配置（**2〜3スクロールに1回**を目安、連打しない） |
| 3 | 各サービス詳細・料金・事例・コンサルタントページの末尾に主CTA |
| 4 | コラムは記事中盤にテキストCTA（控えめ）、記事末にサービス誘導ボックス |
| 5 | 1画面内で主CTA は1つ。副CTA（LINE）は並べても主CTAより弱く |
| 6 | CTA 直上に「次に何が起きるか」を1行で記載（例：予約後、日程調整のご連絡をします） |
| 7 | 予約フォームページではヘッダー・フッター導線を簡素化し離脱を減らす |
| 8 | プライバシーポリシー・利用規約・特商法表記ページには固定CTAを出さない |

### 5-6. スマホ固定CTA（スティッキーフッター）

- **表示**：FV を過ぎたらフッター固定で表示（FV 内に既に CTA があるため重複回避）。
- **構成**：2分割 ＝ 左：LINE（小）／右：主CTA「相談する」（大、幅 60〜65%程度）。ラベルは短縮形「中学受験について相談する」が収まらない場合は「相談する」＋アイコンで可。
- **非表示**：予約フォーム・問い合わせフォーム・法務ページ、および入力中（キーボード表示時）。
- **高さ**：コンテンツを隠しすぎない（目安 56〜64px ＋セーフエリア）。
- PC ではヘッダー右上に主CTA を常設（固定ヘッダー）で代替。

### 5-7. LINE 併用方針

| 項目 | 方針 |
|---|---|
| 位置づけ | **相談予約の代替ではなく「今すぐではない層」の受け皿**。主CV は常にWeb予約 |
| 友だち追加の動機 | 相談前チェックシート、学年別の「時期ごとの確認ポイント」、コラム更新通知など実用的なもの。不安を煽る特典名は不可 |
| リッチメニュー | 「相談予約」「料金」「相談できること」「よくある質問」「コラム」 |
| 配信頻度 | 月2〜4回程度を目安（要確認）。ブロック率を監視 |
| LINE での個別相談 | 実施可否・範囲・返信体制を要確認。実施しない場合は「LINE では予約・お知らせのみ」と明記 |
| 計測 | 流入経路別の友だち追加URL/QRを使い分け、チャネル別の追加数を把握 |

| 流入 | FV/お悩みの差し替え | CV の置き方 |

## 8. CV 戦略（CVR 改善の仮説）

| # | 仮説 | 検証方法 | 関連フェーズ |
|---|---|---|---|
| H1 | 料金を CTA 近くに明示すると、フォーム到達後の離脱が減り、予約後のキャンセルも減る | 料金併記あり/なしの A/B | 比較検討 |
| H2 | 「勧誘しません」「塾に知られません」等の不安解消コピーを予約フォーム直前に置くと完了率が上がる | フォーム直前の不安解消ブロック有無 A/B | 不安解消 |
| H3 | 相談内容を**選択式（複数選択可）**にし自由記述を任意にすると、完了率が上がる | 入力開始→完了率の比較 | 相談予約 |
| H4 | 記事末 CTA を「該当サービス名入り」にすると、汎用 CTA よりクリック率が上がる | cta_click（article_end）の比較 | 検索起点 |
| H5 | SNS 流入は LINE を併置した方が、最終的な相談予約数（LINE経由含む）が増える | LP で LINE 併置あり/なし比較、LINE 経由予約の追跡 | SNS起点 |
| H6 | コンサルタントの顔・経歴・メッセージを TOP 上部寄りに出すと、紹介・指名流入の CVR が上がる | セクション順入替テスト | 興味〜比較 |
| H7 | 「どれを選べばいいか分からない方は戦略相談へ」の受け皿で、サービス選択の迷い離脱が減る | サービス一覧→予約遷移率 | 比較検討 |
| H8 | 予約フォームで日程を先に選ばせる（カレンダー型）方が、後から日程調整するより予約完了→実施率が上がる | 予約方式比較（ツール選定と連動） | 相談予約〜実施 |
| H9 | 「次に何が起きるか」（予約後の流れ）を CTA 直上に明記すると CTR が上がる | マイクロコピー有無 A/B | 全体 |
| H10 | 実在の支援事例（課題→分析→提案→実行→結果）は、抽象的な「選ばれる理由」より自分ごと化を促す | 事例閲覧者と非閲覧者の CVR 比較 | 比較検討 |

**運用ルール**
- 公開直後はトラフィックが少なく A/B の有意差が出にくいため、まずは H1・H2・H3・H9 を**設計段階で実装（ベストプラクティスとして初期反映）**し、流入が増えた段階で検証する。
- CVR 目標値は実績データがないため**仮置きしない**。公開後1〜2か月の実測値を基準に設定する。

## 9. ユーザー確認事項リスト

### 9-1. CV・CTA に直結（最優先）
1. **無料相談の実施有無**（実施する場合：時間・回数・範囲・対象・有料プランとの違い）
2. 初回相談の料金・所要時間・形式（オンライン/対面/電話）・対応エリア
3. 相談予約の方式（自社フォーム／外部予約ツール［例：カレンダー型］／メール調整）
4. 予約後の連絡までの目安日数、営業日・受付時間
5. 問い合わせフォームと予約フォームを分けるか
6. 電話受付の有無
7. キャンセル・日程変更ポリシー

### 9-2. LINE・SNS
8. LINE 公式アカウントの有無・開設予定、LINE での個別相談対応の可否と範囲
9. 既存の Instagram / X / YouTube / TikTok アカウントの有無と運用体制（担当者・更新頻度）
10. コンサルタントの顔出し・実名・動画出演の可否
11. 友だち追加特典（チェックシート等）を用意できるか

### 9-3. 実績・信頼要素（事実確認）
12. 掲載可能な支援事例の有無と、掲載許諾の取得状況
13. 掲載可能なお客様の声の有無と許諾状況（匿名可否、学年・地域の表記範囲）
14. コンサルタントの経歴として公開可能な事実（指導歴、所属歴、資格等）
15. 相談件数・継続率などの数値を公開できるか（公開する場合は根拠データ）
16. 「勧誘しない」方針を明記してよいか（運用上担保できるか）
17. 塾・学校名に言及する方針（コラム内での言及可否）

### 9-4. 広告・集客
18. 広告予算の有無と月額の目安、運用者（社内/代理店）
19. 重点エリア（首都圏・関西・全国オンライン等）
20. 重点ターゲット学年（幼児・低学年・4〜6年）とサービスの優先順位
21. 繁忙期の対応可能枠（予約上限）— 集客量の上限設定に必要
22. 紹介制度（紹介特典）を設けるか
23. コラムの執筆体制（コンサルタント本人の監修が可能か）
