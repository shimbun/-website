## 1. 事業戦略（Agent 01）

### 1-1. 現状認識
- Web調査では「COMPASS 中学受験コンサルタント」の公式サイト・SNS・代表者情報は**確認できなかった**。事実として扱えるのは指示書の内容のみ。
- 「COMPASS／コンパス」を冠する**別の教育事業者が多数存在**（出願システム「miraicompass」、株式会社COMPASS（Qubena）、個別指導コンパス等）。→ **サイト内表記は「COMPASS 中学受験コンサルタント」で統一し、運営者名を明示**。商標調査は専門家に依頼推奨。

### 1-2. 市場
- 首都圏の中学受験者数は2023年に過去最多（約52,600名）、2026年は約52,050名・受験率18.06%（首都圏模試センター集計、公開情報）。**「拡大期」から「高水準で選ばれる時代」へ**。情報過多・SNSの煽り投稿の中で「落ち着いて整理してくれる相談先」の需要がある、と推論。

### 1-3. ポジショニング・ステートメント
> 塾の面談だけでは判断に自信が持てない中学受験家庭に向けて、COMPASSは、特定の塾や教材に縛られない第三者の立場から、志望校・塾・学習計画・家庭学習を**一つの戦略として整理する「セカンドオピニオン型」**の中学受験コンサルタントです。授業をするのではなく、ご家庭が納得して次の一手を決められるよう支援します。

※「特定の塾や教材に縛られない」は**紹介料・提携がないことが前提【要確認】**。

### 1-4. USP
1. **第三者のセカンドオピニオン** — 今の塾を前提にせず、方針の妥当性を点検（転塾させる／続けさせることを目的にしない）【中立性の要確認】
2. **ばらばらの悩みを「一つの戦略」に** — 志望校・併願・塾・家庭学習・模試・過去問を一貫した計画に
3. **保護者が「決められる」状態をつくる** — 選択肢と判断基準を、専門用語を使わずに整理
4. **単発相談から継続支援まで選べる** — 押し売りしない段階設計【料金体系の要確認】
5. （候補）専門性の裏付け — **経歴確認後にのみ掲載**

### 1-5. ペルソナ（設計用・架空）
- **A：小5の母「今の塾のままでいいのか」** — 成績停滞、塾面談では塾内の最適解しか出ない
- **B：小2の母「受験するか、何から始めるか」** — 自分に受験経験がなく情報が多すぎる
- **C：小6の母「志望校・併願の最終判断」** — 模試結果の読み方、併願パターンで迷う

### 1-6. 他サービスとの違い（中立的に表現。他社名は出さない）
| | 塾 | 家庭教師・個別 | COMPASS |
|---|---|---|---|
| 主な役割 | 授業・カリキュラム | 個別の学習指導 | **判断の整理と戦略提案** |
| 立場 | 自塾の中での最適 | 指導を前提 | **特定サービスを前提にしない第三者** |
| 併用 | — | 塾と併用 | **塾・家庭教師と併用する前提** |

### 1-7. サイトで必ず伝える9メッセージ
誰に（受験前の迷い段階〜直前期の保護者）／何を（授業ではなく整理と戦略）／なぜ第三者か（否定ではなく点検）／どう進むか（5ステップ）／いくらか／誰が対応するか／約束しないこと（合格保証はしない）／ハードルの低さ（まとまっていなくてよい）／最終CTA。

## 2. マーケティング・導線（Agent 02）

### 2-1. チャネルの役割
| チャネル | 役割 | 着地先 |
|---|---|---|
| 自然検索 | **長期の主力**（悩みKW→コラム） | コラム記事 → サービス |
| 検索広告 | 短期の顕在層獲得（「中学受験 相談」等） | 広告用LP or TOP |
| 紹介 | CVR最高。指名検索を生む | TOP |
| Instagram | 共感・想起（煽らないトーン自体が差別化） | プロフィール→TOP/LP |
| X / TikTok | 補助（TikTokは効果が仮説段階） | LP |
| LINE公式 | **「今すぐではない層」の受け皿**（相談予約の代替にしない） | リッチメニュー→予約/料金 |
| YouTube | 専門性と人柄の証明（中期） | 概要欄→TOP |

参考：塾選びの情報源は「ネット検索」約45%、「親同士の口コミ」約36%（公開調査）。

### 2-2. カスタマージャーニー
認知 → 興味（悩みの言語化）→ 比較検討（料金・人・事例）→ 不安解消（FAQ・勧誘しない方針）→ 相談予約 → 継続

**原則：料金・コンサルタント・相談の流れの3点を、どのページからも2クリック以内で見られること。**

### 2-3. 主要ユーザーフロー
1. **検索記事起点**：コラム → 記事末の関連サービス → 料金 → 相談予約
2. **TOP起点**（指名・紹介）：TOP → COMPASSとは／コンサルタント → 料金 → 相談予約
3. **SNS/広告起点**：LP（10セクション・流入別にFVと悩み欄を差し替え）内で完結 → 相談予約
4. **比較検討層**：料金 → FAQ → 事例 → 相談予約

### 2-4. CVポイント
- **マクロCV**：相談予約フォーム送信（主）、一般問い合わせ送信（副）
- **マイクロCV**：LINE友だち追加クリック、料金ページ閲覧、FAQ展開、フォーム開始

### 2-5. 集客ロードマップ
- 短期（〜3か月）：サイト基盤、検索広告（予算次第）、LINE、Instagram、初期コラム優先度1〜2
- 中期（3〜12か月）：コラム拡充・リライト、季節施策（新学年・夏期・直前期）、YouTube
- 長期（12か月〜）：指名検索増、紹介の仕組み化

## 3. サイトマップ・URL設計（Agent 03/05 統合・Agent 00 決定）

> 部署間で差異があったため以下で確定：サービスは `/services/`（複数形）、お客様の声は `/voices/`、**相談予約は `/consultation/`**（SEO部案、KW「相談」を含む）、一般問い合わせは `/contact/` に分離。

│   ├─ /services/juku/              塾選び・転塾相談（家庭教師の検討含む）
│   ├─ /services/home-study/        家庭学習相談
│   └─ /services/continuous/        継続コンサルティング
├─ /price/                          料金（全プラン・支払方法・キャンセル規定）
├─ /flow/                           ご相談の流れ
├─ /consultants/                    コンサルタント紹介（＋ /consultants/{slug}/ 複数名の場合）
├─ /cases/                          支援事例一覧（＋ /cases/{slug}/）
├─ /voices/                         お客様の声
├─ /column/                         コラム一覧
│   ├─ /column/category/{slug}/     カテゴリ（記事5本未満の間は noindex）

├─ /consultation/                   相談予約フォーム ★最重要CVページ
│   ├─ /consultation/confirm/       確認
│   └─ /consultation/thanks/        完了（noindex、日程調整へ誘導）
├─ /contact/                        一般お問い合わせ（取材・法人等。フッターのみ）

### 4-8. アクセシビリティ

## 5. コピー方針（Agent 04）

### 5-1. トーン
「売る」ではなく**「保護者の不安を整理する」**。丁寧語、語彙の軸は「整理する・判断材料・選択肢・一緒に」。
**法務部の指摘により「指導・授業・教える」は原則使わず「相談・整理・提案」を使う**（特定継続的役務提供の該当性判断が確定するまで安全側）。

### 5-2. NGワード（抜粋）
| NG | 言い換え |
|---|---|
| 絶対合格／必ず合格／合格保証 | 納得して受験校を決められるよう支援します |
| 偏差値◯◯アップ | 成績が伸びない原因を一緒に整理します |
| No.1／業界最高 | （使わない） |
| 今すぐ／限定◯名／手遅れになる前に | 迷っている段階でのご相談も歓迎しています |
| 塾では教えてくれない | 塾とは違う立場から、別の視点をお伝えします |
| 最短／逆転合格 | （使わない） |

| 用途 | 無料相談なし（**既定**） | 無料相談あり（確認後のみ切替） |
|---|---|---|
| 主CTA | 中学受験について相談する | 無料で相談してみる |
| 短縮（ヘッダー・固定バー） | 相談を予約する | 無料相談を予約する |
| 中間CTA | 相談内容と料金を見る | 無料相談でできることを見る |
| 記事末 | ◯◯について相談する（例：塾選び・転塾について相談する） | ◯◯について無料で相談する |
| CTA近傍 | 相談料 ○○円（税込）／○分 | 初回無料（○分・回数・条件を明記） |

- 文言は `site-settings` で一括切替可能にする（実装要件）。
- 1ページ内でプライマリ文言を混在させない。「お問い合わせ」はフッターの一般問い合わせのみ。
- 系統A（無料なし）では「無料」をヘッダー・FAQ・meta・構造化データ含め**全箇所で不使用**。

### 5-5. サービス6種の型
各サービスページ：こんな方に／相談できること／進め方／得られるもの（保証表現にしない）／料金／よくある質問／関連コラム／主CTA。

### 5-6. FAQ
30問・5分類（A サービス／B 対象・相談内容／C 料金・契約／D 進め方／E 安心・プライバシー）。TOPに7問抜粋。`docs/analysis/04-copywriting.md` §9 を原稿のベースとし、料金・形式・提携の有無など【要確認】の回答は確認後に確定。

## 7. 信頼性設計（Agent 06）

### 7-1. 方針
**「言い切り」ではなく「開示」で不安を解消する**。相談前の不安20項目（誰が？いくら？勧誘は？塾に知られる？子どもも同席？合わなかったら？等）に、ページ上の具体的な開示を対応させる。

### 7-2. 掲載ルール
- **代表・コンサルタント**：氏名・写真・経歴・指導経験・資格・考え方。**確認できた事実のみ、空欄項目は非表示**
- **「COMPASSの考え方」**：相談姿勢／中立性（紹介料の有無を明記）／家庭方針の尊重／**合格保証をしない理由の誠実な説明**
- **支援事例**：課題→分析→提案→実行→結果。掲載基準7項目（本人同意・個人特定不可の加工・結果は事実のみ・成績変化は条件明記 等）。結果は合否ではなく「方針が決まった」等の変化を中心に
- **お客様の声**：学年／性別／通塾状況／悩み／相談内容／相談後の変化。**2段階の許諾**（内容確認＋公開範囲）、謝礼がある場合は明記（ステマ規制）
- **実績数値**：根拠記録のあるものだけ、期間・定義・時点を注記。合格実績・偏差値アップは原則出さない
- **対応範囲外の明示**：学習指導そのもの・医療的診断・塾のあっせん等（【要確認】）と「代わりにできること」

### 7-3. ヒアリングシート
`docs/analysis/06-trust-quality.md` §10（A事業者／B代表／Cコンサルタント／Dサービス方針／E実績・声／F法務、約50項目）をクライアント記入用として使用。

## 8. 法務・コンプライアンス（Agent 09）※最終判断は専門家確認

| 論点 | 判断・対応 |
|---|---|
| 特定商取引法（通信販売） | **ほぼ確実に該当** → `/tokushoho/` 設置。Web上で有償契約が成立する場合は最終確認画面の表示義務 |
| 特定継続的役務提供（家庭教師等・学習塾） | **継続コンサルが該当し得る（★要専門家）**。判定：期間2か月超・金額5万円超・子ども本人への学力の教授を含むか。該当すれば書面交付・クーリングオフ8日・中途解約上限が必要 → 確定まで**コピーで「指導・授業」を避ける** |
| 消費者契約法 | 合格保証は断定的判断の提供に該当し得る。全部免責条項・平均的損害を超えるキャンセル料は無効になり得る → 規約・キャンセル料は★要専門家 |
| 景品表示法・ステマ規制 | NG→OK対照表に従う。数値は定義・期間・母数・出典付き、根拠資料を保管。関係者による口コミ投稿禁止、PR表記ルール |
| 個人情報保護法 | 子どもの氏名は取得しない。自由記述に要配慮個人情報が含まれ得る前提で任意化・同意取得。委託先（Cloudflare・メールAPI・TimeRex等）と外国移転の情報提供をポリシーに記載 |
| 電気通信事業法 外部送信規律 | 原則対象外と考えられるが、**任意でCookie・外部送信の説明をプライバシーポリシーに掲載** |
| 商標 | 「COMPASS」の商標調査（弁理士）を推奨 |

- フォーム同意：プライバシーポリシー同意は必須チェック（初期値オフ）、メルマガ等は任意で別チェック。
- 同意書テンプレート：お客様の声・事例（15項目）、写真（14項目）→ `09-legal-compliance.md` §3〜4。
- 規約類の章立て：プライバシーポリシー20章、利用規約21章（キャンセル・返金・日程変更・録音録画・秘密保持・免責）→ 同 §6〜7。
- **公開前に弁護士レビュー**：利用規約・キャンセル規定・免責・特商法表記・特定継続的役務の判定。
